
# End-to-End Machine Learning Project using Logistic Regression

This repository contains an end-to-end Machine Learning pipeline built using Google Colab.

## 📁 Repository Structure
- `end_to_end_ml.ipynb`: Jupyter notebook containing data preprocessing, EDA, and model training.
- `placement.csv`: The dataset used for model training and evaluation.

## 📊 Dataset
The project uses the `placement.csv` dataset to predict student placement outcomes based CGPA and IQ.

## 🚀 How to Run
1. Open `end_to_end_ml.ipynb` directly in Google Colab.
2. Upload `placement.csv` or mount your Google Drive to load the dataset.
3. Run all cells sequentially to execute the pipeline.
